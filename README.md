# website-vibecoder

Персональный лендинг-портфолио вайбкодера.

Одностраничный сайт на чистых **HTML**, **CSS** и **JavaScript** — без фреймворков, сборщиков и установки зависимостей. Есть отдельная страница политики конфиденциальности.

## Разделы сайта

1. Шапка с навигацией  
2. Главный экран  
3. Обо мне  
4. Услуги  
5. Как проходит работа (процесс)  
6. Проекты (примеры работ)  
7. Преимущества  
8. Форма заявки и контакты  
9. Подвал  

Дополнительно: страница `privacy.html` — политика конфиденциальности (шаблон; перед публичным использованием желательна юридическая проверка).

## Технологии

- HTML5  
- CSS3 (адаптив, анимации)  
- JavaScript (без библиотек)  
- Шрифты Google Fonts: Manrope и Space Grotesk (подключаются из интернета)

## Как открыть сайт локально

1. Откройте папку проекта.  
2. Дважды кликните `index.html` — страница откроется в браузере.  
3. Либо запустите простой локальный сервер из папки проекта:

```bash
npx --yes serve .
```

После запуска обычно открывается адрес вида `http://localhost:3000`.

## Что можно персонализировать

| Что | Где |
|-----|-----|
| Имя / бренд | `index.html` — шапка, главный экран, подвал |
| Подпись / профессия | главный экран и подвал |
| Текст «Обо мне» и статистика | блок `#about` |
| Услуги, процесс, преимущества | соответствующие секции в `index.html` |
| Карточки проектов, ссылки, изображения | блок `#projects`, папки `projects/` и `images/projects/` |
| Telegram, почта, VK | раздел контактов, подвал, `script.js` (mailto в форме) |
| Политика конфиденциальности | `privacy.html` |
| SEO (title, description, Open Graph) | секция `<head>` в `index.html` |

## Поведение сайта

- Навигация плавно прокручивает к разделам.  
- На мобильных открывается бургер-меню.  
- Форма проверяет обязательные поля и согласие на обработку персональных данных.  
- После успешной проверки открывается почтовый клиент (`mailto`) с заполненной заявкой.  
- Кнопка «Написать в Telegram» ведёт в мессенджер напрямую.  
- Блоки плавно появляются при прокрутке (отключается при `prefers-reduced-motion`).
